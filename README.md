# Trekking Management Application

A Flask-based trekking management system for administrators, trek staff, and trekkers.

## Features
- Admin dashboard for managing treks, staff, users, and bookings
- Trek staff dashboard for assigned treks and participant management
- User dashboard for browsing and booking treks
- SQLite-backed data storage

## Tech Stack
- Python
- Flask
- Flask-SQLAlchemy
- Jinja2
- SQLite

## Setup
1. Create and activate a virtual environment
2. Install dependencies: `pip install -r requirement.txt`
3. Run the app: `python app.py`
